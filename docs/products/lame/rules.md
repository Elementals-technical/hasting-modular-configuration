## 7. Залежності та правила
### 7.1 Тумби і розміщення
1. Якщо Cabinet Type = Sink Base, то Width ∈ {60, 80, 100, 120}; якщо Side Cabinet — Width ∈ {40, 60, 80, 100, 120}
2. Якщо Cabinet Style = 1 Drawer, висота 26 см; якщо 2 Drawer — 52 см. Глибина завжди 52 см
3. Якщо хоч одна тумба 2 Drawer, усі тумби мають бути 2 Drawer, і навпаки ("2DW can only be used with 2DW cabinets"). Тому вся композиція має одну висоту
4. Якщо в тумбі вже 2 Sink Base, трету додати не можна (картка вимкнена). Кількість Side Cabinet не обмежена.
5. Якщо додавання або розширення тумби зробить загальну довжину композиції (стільниці) більшою за 220 см (86.6"), дія блокується з повідомленням "Maximum composition length reached…". Для Solid Surface (Matte White) ліміт може не спрацювати — перевірити на тесті
6. Тумби стоять впритул в один ряд; стільниця йде на всі. Вільного розміщення, стекінгу чи окремих тумб немає.
7. Стилю 1DWID немає, тому обмеження "Sink Base 60 см + 1DWID" немає

### 7.2 Оздоблення
8. Патерн один на композицію: зміна патерну діє на всі тумби; нова тумба бере патерн композиції
9. Будь-який патерн дозволений з будь-яким кольором корпусу
10. Колір корпусу, колір ручки й патерн діють на всю композицію; зміна кольору корпусу не змінює патерн, ручку, заглушки й undertop; ніжки йдуть за кольором корпусу

### 7.3 Стільниця і раковина
11. Одна стільниця на всю композицію (довжина = сума ширин усіх тумб), глибина 52 см; колір і товщина діють на всю стільницю.
12. Матеріал стільниці визначає товщину і інтегровані раковини:

| Матеріал | Товщина | Інтегровані раковини | Мін. Sink Base |
| :---- | :---- | :---- | :---- |
| Solid Surface | 0.5" | LB440, LB175, LB575, LB856, VA030 | 60 см |
| HPL | 0.5" | VA024 | 60 см |
| Porcelain | 0.8" | LV890, LV892 | 60 см |
| Glass MT / Glass GL | 0.5" | VA002, VA005 | 60 см |

13. Якщо змінюється колір стільниці, товщина лишається, якщо ще дозволена, інакше стає першою дозволеною; раковини, що більше не підходять, скидаються і вибирається перша дозволена [code: UI countertop compatibility].
14. Якщо товщина дозволена не для всіх Sink Base, зміна відхиляється.
15. Якщо Countertop Style = Vessel, Basin Style пропонує None / Iris / Frame / Plaza і з'являється Vessel Color; Iris і Frame — лише Lacquered MT, Plaza — Lacquered MT і GL.
16. Якщо стиль повертається на Integrated, vessel і його колір скидаються.
17. Отвори під змішувач: 0–3 для всіх матеріалів.
18. Лише тонкі стільниці: кронштейнів, раковин поза Sink Base (hosted), зсуву стільниці та плаваючої стільниці немає.

### 7.4 Ніжки і undertop
19. Якщо Leg Cap Color вимкнено, ніжок немає; якщо ввімкнено без кольору — заглушки в кольорі ручки; з кольором — заглушки в цьому кольорі. Ніжки діють на всю композицію, нова тумба їх наслідує
20. Якщо стиль ящиків змінюється, змінюється модель ніжки (1 Drawer — довга, 2 Drawer — коротка) і SKU ніжки
21. Якщо undertop увімкнено, він іде на всю довжину композиції, а стільниця й раковини піднімаються на 2 см; без кольору — у кольорі ручки
22. Якщо в композиції є Sink Base 60 см, undertop за клієнтом недоступний — **Not implemented** (збірка дозволяє)

### 7.5 Заборонені комбінації (підсумок)
| Комбінація | Результат |
| :---- | :---- |
| Sink Base 40 см | не пропонується |
| Третя Sink Base | вимкнена |
| Композиція довша за 220 см | блокується (див. застереження для Solid Surface, правило 5) |
| 1 Drawer разом із 2 Drawer | не змішуються |
| Різні патерни на різних тумбах | неможливо (один патерн на композицію) |
| Раковина іншого матеріалу стільниці | прихована |
| Товщина, не дозволена для матеріалу | прихована |
| Колір Lacquered GL для Iris / Frame | вимкнено |
| Undertop із Sink Base 60 см | за клієнтом заборонено; у збірці **не блокується** |
