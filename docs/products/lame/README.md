## Що таке Lame

- Модульна тумба з ящиками з Sink Base і Side Cabinet, що стоять впритул в один ряд під однією тонкою стільницею
- Висоту задає кількість ящиків: 1 Drawer = 26 см, 2 Drawer = 52 см; в одній тумбі всі шафи мають однаковий стиль ящиків
- Одна ручка G58 без вибору стилю; фасади ящиків мають один із п'яти патернів (Galles, Gessato, Oxford, Piquet, Plisse), один патерн на всю композицію
- Опційно: ніжки з декоративними заглушками і undertop (акцентна смуга між стільницею і ящиками); лише тонкі стільниці

## Ключові числа

43 моделі Prebuilt (18 з ніжками) · 103 SKU у клієнта · кольори: корпус 40, ручка 22, заглушки ніжок 22, undertop 22, стільниця 70, vessel 40 · патерни 5 (один на композицію) · товщини 2 · раковини 10 інтегрованих + 3 vessel · довжина ≤ 220 см. Сценарії: 5 кроків (Color містить патерн, ручку, ніжки й undertop; Faucet Details окремо).
