## 6. Аксесуари
### 6.1 Доступно: ніжки з заглушками
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Color", блок "Leg Cap Color" з перемикачем "Enable Legs, Then Color" (обидва сценарії) |
| Опції | вимк. / увімк. (заглушки в кольорі ручки) / увімк. + один із 22 кольорів заглушки |
| Скільки | одна пара ніжок на композицію, під крайніми тумбами |
| На чому можна | будь-яка композиція Sink Base / Side Cabinet, обидва стилі ящиків |
| Колір | ніжка — колір корпусу; заглушка — Gold, Silver або 20 Lacquered MT |
| Висота | 1 Drawer → довга ніжка (SKU 22.6"), 2 Drawer → коротка (SKU 12.4") |
| Моделі | 18 моделей Prebuilt "Legs" стартують з ніжками; Create your own — без ніжок |
| Ціна | 2 ніжки + 2 заглушки на композицію; ніжка за стилем ящиків і матеріалом корпусу (LACM / LACG), заглушка $0 — **Provisional** (за штуку чи за пару, LAME-ACC-03) |
| Відомо | модель з ніжками провалюється в підлогу [backlog: #83], не взято в роботу |

* Клієнт визначає 4 висоти ніжок (Countertop Style × Cabinet Style): Integrated 57.5 / 31.5 см, Vessel 51.5 / 25.5 см. Збірка має лише висоти для Integrated; окремих висот для vessel немає — **Not implemented** (SKU клієнта для них також немає, LAME-ACC-02)
