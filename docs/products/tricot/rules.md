## 7. Залежності та правила
### 7.1 Тумби і розміщення
1. Якщо Cabinet Type = Sink Base, то Width ∈ {60, 80, 100, 120}; якщо Side Cabinet — Width ∈ {40, 60, 80, 100, 120}
2. Висота завжди 40 см, глибина завжди 52 см для всіх типів і стилів ящиків
3. Якщо в тумбі вже 2 Sink Base, третю додати не можна (картка вимкнена) . Кількість Side Cabinet не обмежена.
4. Якщо додавання або розширення тумби зробить тумбу довшою за 220 см (86.6"), дія блокується з повідомленням "Maximum composition length reached…" . Бокові панелі враховуються (+1 см кожна). .
5. Тумби стоять впритул в один ряд; стільниця йде на всі. Вільного розміщення, стекінгу чи окремих тумб немає.
6. Якщо хоч одна тумба 2DW, усі тумби мають бути 2DW; 1DW і 1DWID можна змішувати
   - Вибір стилю іншої групи після підтвердження перемикає всі тумби
7. Якщо Sink Base 60 см і 1DWID, інтегрована стільниця недоступна (лише vessel); зміна на 1DWID для Sink Base 60 см із інтегрованою стільницею відхиляється

### 7.2 Оздоблення
8. Якщо колір корпусу Lacquered MT, активний лише Loden; якщо Wood Veneer — активні Cannette, Twill, Gessato, Satin
9. Якщо колір корпусу змінюється на матеріал, який не приймає поточний патерн, патерн стає першим дозволеним (Loden для лаку, Cannette для дерева)
10. Нова тумба бере патерн тумби, якщо він дозволений, інакше Satin, інакше перший дозволений
11. Колір корпусу й колір пазу діють на всю тумбу; патерн зберігається на кожну тумбу . Клієнт дозволяє різні патерни на різних тумбах; чи може користувач задати це для окремої тумби в поточному UI — перевірити на тесті.
12. Якщо колір пазу дорівнює кольору корпусу і колір корпусу змінюється на інший лак, паз йде за ним; на шпон.

### 7.3 Стільниця і раковина
13. Одна стільниця на тумбу, на всю довжину, глибина 52 см, лежить на тумбах 40 см; колір і товщина діють на всю стільницю [3D: countertop] [table 593].
14. Матеріал стільниці визначає товщину і інтегровані раковини:

| Матеріал | Товщина | Інтегровані раковини | Мін. Sink Base |
| :---- | :---- | :---- | :---- |
| Solid Surface | 0.5", 4.7" | LB440, LB175, LB575, LB856 | 60 см |
| Solid Surface | 3.1" | VA023 | 80 см |
| HPL | 0.5", 4" | VA024 | 60 см |
| Porcelain | 0.8", 4.7" | LV890, LV892 | 60 см |
| Glass MT / Glass GL | 0.5" | VA002, VA005 | 60 см |

15. Якщо змінюється колір стільниці, товщина лишається, якщо ще дозволена, інакше стає першою дозволеною; раковини, що більше не підходять, скидаються і вибирається перша дозволена [code: UI countertop compatibility].
16. Якщо товщина дозволена не для всіх Sink Base, зміна відхиляється [code: UI countertop compatibility].
17. Якщо Countertop Style = Vessel, Basin Style пропонує None / Iris / Frame / Plaza і з'являється Vessel Color; Iris і Frame — лише Lacquered MT, Plaza — Lacquered MT і GL [code: tricot/product-profile.json].
18. Якщо стиль повертається на Integrated, vessel і його колір скидаються [code: UI change plan].
19. Якщо товщина 3.1", 4" або 4.7", до ціни додаються два кронштейни [price: Class xlsx Basin StylePricing G43] [code: tricot/sku-profile.json].
20. У цій збірці немає раковин поза Sink Base (hosted), зсуву стільниці та плаваючої стільниці [3D: placement] [code: tricot/product-profile.json].

### 7.4 Бокові панелі
21. Якщо бокова панель активна, стільниця стає довшою на 1 см з цього боку; якщо це перевищить максимальну довжину, "No groove" вимикається [code: UI side panels] [3D: countertop layout].
22. Бокові панелі лише на повністю відкритих торцях [doc: WebGL Logic P0109] [3D: side panel add-on].

### 7.5 Заборонені комбінації (підсумок)
| Комбінація | Результат |
| :---- | :---- |
| Sink Base 40 см | не пропонується |
| Третя Sink Base | вимкнена |
| Тумба > 220 см (з боковими панелями) | блокується (див. відому проблему для Solid Surface) |
| 2DW разом із 1DW або 1DWID | не змішуються |
| Sink Base 60 см + 1DWID + інтегрована стільниця | відхиляється |
| Loden на Wood Veneer; Cannette/Twill/Gessato/Satin на Lacquered MT | вимкнено |
| VA023 на Sink Base 60 см | вимкнено |
| Раковина іншого матеріалу стільниці | прихована |
| Колір Lacquered GL для Iris / Frame | вимкнено |
