## 6. Аксесуари
### 6.1 Доступно: бокові панелі
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Accessories", блок "Side Panels" (обидва сценарії) |
| Опції | None; No groove (гладка панель). Підписи в 2D клієнта: "None" / "Yes" |
| Розміщення | лише на відкритих торцях тумби ("only to the end of a unit"); при кількох тумбах користувачу показують, з якого боку стане панель |
| На чому можна | Sink Base і Side Cabinet, усі стилі ящиків (висота 40 см) |
| Колір | як колір і матеріал корпусу; без патерну, без пазу |
| Вплив на стільницю | +1 см до довжини стільниці на кожен активний бік |
| Ціна | за кожен активний бік |
| Ліміт | "No groove" вимикається, якщо тумба з панелями перевищить максимальну довжину |
