| Продукт | Код | Ширина (см / дюйми) | Висота | Глибина | Ящики (стиль) | Ручка | Раковина |

| Sink Base | SB | {60, 80, 100, 120} / {23.6, 31.5, 39.4, 47.2} | {40 см / 15.7" для 1DW, 1DWID; 52 см / 20.5" для 2DW} | {52 см / 20.5"} | {1DW, 2DW (Provisional — підлягає видаленню), 1DWID} | {немає — деталь рамки} | так, одна на Sink Base |

* Sink Base 40 см немає: її немає в таблиці 579 і в прайсі клієнта.
* Висоту не вибирають: її задає стиль ящиків. Глибина має одне значення 52 см.
* Side Cabinet у даних зберігається як значення Sink-Cabinet (підпис "Side Cabinet").
* Кількість SKU у клієнта: SB 3 стилі × 4 ширини = 12; SC 3 × 5 = 15 → 27, з них 9 — 2DW.

### 2.3 Ручка і рамка (Frame)
* Ручки немає, вибору немає: "Handle Styles — No option - it is the frame detail" [doc: WebGL Logic P0022].
* Атрибута Handle у профілі немає; селектор Handle у правій панелі прихований; пункт меню "Handle Style" прибрано (#9, Done).
* Frame — не окремий продукт, а колір рамки фасадів ящиків (Frame Color). Cabinet Color фарбує вставку фасаду, Cabinet Side Color — стінки й дно тумби.
* Frame Color визначає ціновий клас тумби: Nero 433 MT → /B, будь-який інший колір → /C (§8).

### 2.4 Типи продуктів, яких у Class немає
* Open Shelf, Side Shelf: немає в тексті Class і в прайсі (на скриншоті UI у документі WebGL картки є) → у збірці не пропонуються; Not in scope, UNKNOWN — clarify щодо скриншоту.
* Бокові панелі, ніжки, патерни / fluting, towel bar, LED, undertop: клієнт для Class не визначає → Not in scope.
