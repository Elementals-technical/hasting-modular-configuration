## Що таке Class

- Тумба з однієї або кількох тумб (Sink Base, Side Cabinet), які стоять впритул в один ряд під спільною стільницею.
- Ручки немає: хват є деталлю рамки ("Handle Styles — No option - it is the frame detail").
- Три кольори корпусу: Cabinet Color (вставка фасаду), Cabinet Side Color (стінки й дно), Frame Color (рамка фасаду).
- Висота залежить від стилю ящиків: 1DW і 1DWID — 40 см, 2DW — 52 см. Дані збірки: конфігуратор матеріалів 8, таблиця стільниць 578, таблиця тумб 579 [code: class/manifest.json].

## Ключові числа

44 моделі Prebuilt (92 тумби; 20 із них 2DW — Provisional, підлягає видаленню) · 27 SKU тумб у клієнта · кольори: вставка фасаду 108 у клієнта / 343 у збірці, бік 52, рамка 20, стільниця 71 / 170 · товщини 5 · раковини 10 інтегрованих + 3 vessel · довжина ≤ 220 см. Сценарії: 5 кроків (Faucet Details окремо, Accessories немає).
