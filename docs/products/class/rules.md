## 7. Залежності та правила
### 7.1 Тумби і розміщення
1. Якщо Cabinet Type = Sink Base, то Width ∈ {60, 80, 100, 120}; якщо Side Cabinet — Width ∈ {40, 60, 80, 100, 120}.
2. Якщо стиль 1DW або 1DWID, висота 40 см; якщо 2DW — 52 см (Provisional — підлягає видаленню). Глибина завжди 52 см.
3. Якщо в тумбі вже 2 Sink Base, третю додати не можна (картка вимкнена). Кількість Side Cabinet не обмежена.
4. Якщо додавання або розширення тумби зробить тумбу довшою за 220 см (86.6"), дія блокується з повідомленням "Maximum composition length reached…". Ліміт 220 см діє для всіх матеріалів, зокрема Solid Surface (Matte White): він береться з таблиці 578 (max_integrated_cm / max_vessel_cm = 220 в усіх рядках; клієнтський GB J5:K21 — те саме). Невизначеним лишається лише Matte White 8cm (Technomat 3.1"), для якого рядка в таблиці 578 немає, а клієнтська примітка обрізана — UNKNOWN — clarify.
5. Тумби стоять впритул в один ряд; стільниця йде на всі. Вільного розміщення, стекінгу, drag and drop чи окремих тумб немає.
6. Якщо хоч одна тумба 2DW, усі тумби мають бути 2DW; 1DW і 1DWID можна змішувати. Тому вся тумба має одну висоту (40 або 52 см). Вибір стилю іншої групи не блокується: він відкриває діалог «Update Design?» із заміною стилю всіх тумб (§3.3).
7. Якщо Sink Base 60 см і 1DWID, інтегрована стільниця за клієнтом недоступна (лише vessel); у збірці Class **не блокується** → Not implemented.

### 7.2 Оздоблення
8. Cabinet Color, Cabinet Side Color і Frame Color діють на всю тумбу й не залежать один від одного (зміна одного не змінює інші).
9. Якщо Frame Color = Nero 433 MT, ціновий клас тумби /B; інакше /C.
10. Нова тумба бере поточні кольори композиції.
11. Glass MT, Glass GL і Smoke Glass у Cabinet Color — Provisional — підлягає видаленню.

### 7.3 Стільниця і раковина
12. Одна стільниця на тумбу, на всю довжину, глибина 52 см, лежить на тумбах 40 або 52 см; колір і товщина діють на всю стільницю [3D: countertop] [table 578].
13. Матеріал стільниці визначає товщину і інтегровані раковини:

| Матеріал | Товщина | Інтегровані раковини | Мін. Sink Base |
| :---- | :---- | :---- | :---- |
| Solid Surface | 0.5", 4.7" | LB440, LB175, LB575, LB856 | 60 см |
| Solid Surface | 3.1" | VA023 | 80 см |
| HPL | 0.5", 4" | VA024 | 60 см |
| Porcelain | 0.8", 4.7" | LV890, LV892 | 60 см |
| Glass MT / Glass GL (Provisional — підлягає видаленню) | 0.5" | VA002, VA005 | 60 см |

14. Якщо змінюється колір стільниці, поля кроку «Countertop & Basin» підбирають значення за таблицею 578: товщина лишається, якщо ще дозволена для нового матеріалу, інакше ставиться перша дозволена; раковина, що більше не підходить, замінюється першою дозволеною (autoSelect: firstAllowed в ui.json) [code: class/ui.json; тест FieldsStepPage.autoSelect].
15. Окремого правила, яке б відхиляло зміну товщини, недозволену для частини Sink Base, у Class немає (ruleData.countertopCompatibility не оголошено, воно є лише в Tricot): недозволені товщини й раковини просто недоступні в полях. Поведінка для композиції з двома Sink Base різної ширини — UNKNOWN — clarify.
16. Якщо Countertop Style = Vessel, Basin Style пропонує None / Iris / Frame / Plaza і з'являється Vessel Color; Iris і Frame — лише Lacquered MT, Plaza — Lacquered MT і GL [code: class/product-profile.json].
17. Якщо стиль повертається на Integrated, vessel і його колір скидаються [code: UI change plan].
18. Якщо товщина 3.1", 4" або 4.7", до ціни додаються два кронштейни [price: Class xlsx Basin StylePricing G43].
19. У цій збірці немає раковин поза Sink Base (hosted), зсуву стільниці та плаваючої стільниці; плаваючу стільницю клієнт визначає → Not implemented.

### 7.4 Аксесуари
20. Faucet Holes: 0–3 для всіх матеріалів; 3 отвори додають $275.
21. Inner drawer dividers (metal / oak) не реалізовані; правил кількості й сумісності з 1DW / 2DW / 1DWID клієнт не задав → Not implemented / UNKNOWN — clarify.
