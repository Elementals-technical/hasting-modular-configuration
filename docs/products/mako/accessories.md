## 6. Аксесуари
Кроку Accessories у Mako немає в жодному сценарії.

### 6.1 Доступно: ніжки
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Color", блок "Leg Color" з перемикачем "Enable Legs, Then Color" (обидва сценарії) |
| Опції | вимкнено (без ніжок) або колір із 22 (Metal 2, Lacquered MT 20) |
| На чому | лише 2 Drawer; для 1 Drawer блок Leg Color прихований |
| Область | один колір ніжок на всю тумбу; у 3D ніжки показуються під кожною тумбою |
| Висота | 33.3 см (13-1/8") за клієнтом |
| Ціна | пара ніжок (2 шт.) на композицію — Provisional; $745 (Metal) або $1,340 (Lacquered MT) за ніжку |
| Положення | клієнт не задає — **UNKNOWN — clarify** |

### 6.2 Доступно: отвори під змішувач
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Faucet Details", блок "Faucet Holes" (обидва сценарії) |
| Опції | 0, 1, 2, 3; спочатку не вибрано, рядка в ціні немає до вибору |
| 3D | отвори не малюються, значення лише в стані й ціні |
| Ціна | 0–2 отвори $0, 3 отвори $275 (прайс аксесуарів Class, на який посилається Mako) |

### 6.3 Немає в збірці
| Аксесуар | Статус | Пояснення |
| :---- | :---- | :---- |
| Inner drawer dividers | **Not implemented** | клієнт: "same as Class" (metal або oak). У профілі й SKU є, але кроку немає, а в 3D ящики Mako не мають зон під роздільники; роздільники Phase 2 розробляються на окремій гілці |
| Side panels | Not in scope | у Mako не визначені (немає в Master File, WebGL і прайсі) |
| Towel bar, LED | Not in scope | у текстах Mako не згадуються |
| Undertop | Not in scope | лише Lame |
| Кронштейн товстої стільниці | Not in scope | лише для товстих стільниць; у Mako тонкі |
| Floating countertop | **UNKNOWN — clarify** | клієнт: "available … only with thick countertops", але Mako лише тонкі; у збірці немає |
