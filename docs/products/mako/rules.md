## 7. Залежності та правила
Порядок залежностей — як в ієрархії §3.4: тип тумби → стиль ящиків (висота, ніжки) → ширина → ручка → кольори → матеріал стільниці → товщина → стиль стільниці → раковина → колір vessel → отвори.

### 7.1 Тумби і розміщення
1. Якщо Cabinet Type = Sink Base, то Width ∈ {60, 80, 100, 120}; якщо Side Cabinet — Width ∈ {40, 60, 80, 100, 120}
2. Якщо Cabinet Style = 1 Drawer, висота 26 см; якщо 2 Drawer — 52 см. Глибина завжди 52 см [table 581]
3. Якщо хоч одна тумба 1 Drawer, усі тумби мають бути 1 Drawer; якщо 2 Drawer — усі 2 Drawer ("2DW can only be used with 2DW cabinets", "1DW can only be used with 1DW cabinets")
   * Вибір стилю іншої групи після підтвердження перемикає всі тумби
4. Якщо в композиції вже 2 Sink Base, третю додати не можна (картка вимкнена). Кількість Side Cabinet не обмежена.
5. Якщо додавання або розширення тумби зробить тумбу довшою за 220 см (86.6"), дія блокується з повідомленням "Maximum composition length reached…" (для Solid Surface і Glass — перевірити на тесті)
6. Тумби стоять впритул в один ряд; стільниця йде на всі. Вільного розміщення, Drag & Drop, стекінгу, окремих тумб і переміщення стільниці немає. Порядок тумб у ряду можна змінити лише обміном із сусідом (меню 3D: Reposition → Move Left / Move Right).
7. Якщо змінюється Handle, нова ручка ставиться на всі тумби (з підтвердженням, якщо тумби вже стоять)

### 7.2 Оздоблення
8. Колір корпусу, колір ручки і колір ніжок діють на всю тумбу
9. Якщо Cabinet Style = 1 Drawer, Leg Color недоступний; якщо тумби переходять з 2 Drawer на 1 Drawer, колір ніжок скидається, ніжки зникають і виходять із ціни
10. Якщо Leg Color порожній, ніжок немає; вибір кольору показує ніжки в 3D і додає їх у ціну
11. Обмежень між кольором корпусу, ручки і ніжок немає; чи можна G50 у лаку — **UNKNOWN — clarify** (§4.3)

### 7.3 Стільниця і раковина
12. Одна стільниця на композицію, на всю довжину, глибина 52 см; лежить на тумбах 26 або 52 см; колір і товщина діють на всю стільницю.
13. Матеріал стільниці визначає товщину і інтегровані раковини [table 577]:

| Матеріал | Товщина | Інтегровані раковини | Мін. Sink Base |
| :---- | :---- | :---- | :---- |
| Solid Surface | 0.5" | LB440, LB175, LB575, LB856 | 60 см |
| HPL | 0.5" | VA024 | 60 см |
| Porcelain | 0.8" | LV890, LV892 | 60 см |
| Glass MT / Glass GL | 0.5" | VA002, VA005 | 60 см |

14. Якщо змінюється колір стільниці, товщина стає дозволеною для нового матеріалу; раковини, що більше не підходять, скидаються і вибирається перша дозволена
15. Якщо Countertop Style = Vessel, Basin Style пропонує None / Iris / Frame / Plaza і з'являється Vessel Color; Iris і Frame — лише Lacquered MT, Plaza — Lacquered MT і GL [code: mako/product-profile.json].
16. Якщо стиль повертається на Integrated, vessel скидається і вибирається перша дозволена інтегрована раковина (повний порядок скидань — перевірити на тесті)
17. Максимальна довжина стільниці 220 см і для Integrated, і для Vessel; понад 220 см обидва стилі недоступні
18. Кронштейнів немає: усі стільниці Mako тонкі
19. Якщо Countertop Style = Vessel, на кожну Sink Base додається виріз під vessel (і для "None")
20. У цій збірці немає раковин поза Sink Base (hosted), зсуву стільниці, плаваючої стільниці і drag-and-drop стільниці [3D: placement].

### 7.4 Ніжки
21. Ніжки лише для 2 Drawer (див. правило 9); одна пара в ціні на всю композицію (Provisional)

### 7.5 Заборонені комбінації (підсумок)
| Комбінація | Результат |
| :---- | :---- |
| Sink Base 40 см | не пропонується |
| Третя Sink Base | вимкнена |
| Тумба > 220 см | блокується |
| 1 Drawer разом із 2 Drawer | не змішуються |
| Leg Color на 1 Drawer | недоступний; скидається при переході на 1DW |
| Різні ручки або кольори ручки на різних тумбах | неможливо (одна ручка й колір на всю тумбу) |
| Товста стільниця (3.1" / 4" / 4.7") | не пропонується |
| Matte White 8cm, VA023, VA030 | не пропонується |
| Раковина іншого матеріалу стільниці | прихована |
| Колір Lacquered GL для Iris / Frame | вимкнено |
| Floating countertop | немає |
