## Що таке Mako

- Модульна тумба з ящиками: Sink Base і Side Cabinet впритул в один ряд під однією стільницею; до 220 см, не більше 2 Sink Base. Клієнт: "similar to Urban Standard Height, but with less optionality".
- Висоту задає стиль ящиків: 1 Drawer = 26 см, 2 Drawer = 52 см; один стиль на всю тумбу. Глибина одна — 52 см.
- Ручка G57 або G50 (одна на тумбу) + колір ручки; ніжки лише для 2 Drawer. Патернів і пазу немає.
- Лише тонкі стільниці (0.5" / 0.8"); раковина інтегрована або vessel (Iris / Frame / Plaza). Кроку Accessories немає; отвори під змішувач — окремий крок.

## Ключові числа

42 моделі Prebuilt (88 тумб) · 36 SKU тумб у клієнта · кольори: корпус 40, ручка 22, ніжки 22, стільниця 70, vessel 40 · товщини 2 · раковини 9 інтегрованих + 3 vessel · довжина ≤ 220 см.
