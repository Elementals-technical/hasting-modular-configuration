## 6. Аксесуари
### 6.1 Доступно: бокові панелі
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Accessories", блок "Side Panels" (обидва сценарії) |
| Опції | None; No groove (NoG); 1 groove (upper) (UpperG) |
| За висотою | 38 і 28 см: No groove і 1 groove (upper); 35 і 25 см: лише No groove — **Provisional** (таблиця висот виведена командою, клієнт не підтвердив) |
| За ручкою | Upper Groove → 1 groove (upper); Push to open → No groove ("Only offer 'Grooved' SPs if Urban handle style is used") |
| Розміщення | на лівому й правому торці композиції; не на торці з Open Shelf / Open Side Shelf |
| Колір | панель — колір і матеріал корпусу; вставка пазу (1 groove) — колір пазу |
| 3D | окремий продукт ULH_UniSidePanel, підлаштовується під висоту 25 / 28 / 35 / 38 і глибину 46 / 50 |
| Вплив на стільницю | +1 см до довжини стільниці на кожен активний бік |
| Ціна | за кожен активний бік, граматика USH (§8.1) |
| Ліміт | вимикається, якщо стільниця з панелями перевищить максимальну довжину, або якщо довжина композиції рівно 340 см |

* Ступінчасті й дворядні композиції: клієнт рахує 3 або 4 відкритих торці; скільки панелей ставить збірка на Multi-Level — **UNKNOWN — clarify** (перевірити на тесті)

### 6.2 Доступно: рушник (Towel Bar) — Provisional
| Пункт | Значення |
| :---- | :---- |
| Де | крок "Accessories", блок "Towel Bar" |
| Опції | None (дефолт), Left, Right, Both |
| 3D | TowelBar40_R, з вибраного боку або з обох |
| Колір | група Towel Bar Color конфігуратора 4; блок кольору лише коли рушник вибрано |
| Ціна | за кожен бік, граматика USH |

* Клієнт: "Accessories – Same as Urban Standard Height"; чи підходить рушник до висот 25–38 см, клієнт не підтвердив

### 6.3 Немає в збірці
| Аксесуар клієнта (через USH) | Статус |
| :---- | :---- |
| Inner drawer dividers (A / B / C) | **Not implemented** — у шафах ULH немає точок для роздільників; нові роздільники в розробці (#65) |
| Faucet holes 0 / 1 / 2 / 3 і їх позиція | **Not implemented** — блоку немає; у ціні завжди рядок "0 отворів" ($0) |
| Book matching, Grain direction, Inner LED | Book matching — клієнт у xlsx (лист Accessories Pricing) вказує брати SKU з Urban Standard Height; у збірці ULH не реалізовано (**Not implemented**). Grain direction і Inner LED — клієнт для ULH явно не пише, у збірці немає (**UNKNOWN — clarify**) |
| Hole cutout | автоматичний рядок для vessel (§8.1), окремого вибору немає |
| Electrical outlet | Not in scope ("Future") |
