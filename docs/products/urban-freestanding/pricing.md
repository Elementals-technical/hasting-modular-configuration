## 8. Ціноутворення
Разом = Σ тумб (SB, SC, коротка, OS, OSS) + Σ бокових панелей + стільниця (+ нижня стільниця) + на кожну Sink Base (інтегрована раковина або виріз + vessel) + рядок отворів під змішувач + Σ рушникотримачів. Кожен рядок — один SKU, ціну дає сервіс цін; конфігуратор не має власного прайсу [code: UI pricing]. Прайс UF містить лише тумби (466 SKU); стільниця, раковини, vessel, бокові панелі й рушникотримач оцінюються як в Urban Standard Height (USH) → **Provisional**.

Приклади [code: UI SKU tests]: VAN-URFS-SB/2DW/UG/X-23.6W-35.8H-19.7D-CAB-HPL-TKF-HDL-HPL-TKF; VAN-URFS-SB/2DW/PTO/X-23.6W-34.6H-19.7D-CAB-HPL-TKF; VAN-URFS-SC/1DW/UG/X-23.6W-22H-19.7D-…; VAN-UROS-3S-9.8W-34.6H-19.7D-CAB-3D-1A1; VAN-UROSS-L-5.9W-33.5H-18.1D-….

* Висота в SKU тумб SB / SC / короткої — з цоколем (91 → 35.8H, 88 → 34.6H, 56 → 22H, 53 → 20.9H); в SKU Open Shelf і Open Side Shelf — без цоколя (88H → 34.6H, 85H → 33.5H), як у прайсі клієнта
* Елемент HDL додається лише при UG або CG; без окремого вибору паз кодується кольором корпусу
* Розміри в SKU — дюйми з одним знаком після коми; у рядках прайсу клієнта — см (60W-91H-50D), у прикладі Pricing C2 — дюйми → формат підтвердити (GEN-SKU-02)
* Ціни тумб у прайсі клієнта (без fluting, будь-яка ручка й глибина): Sink Base 60 см — від $2834 (3D) до $4038 (HPL / ESS); Side Cabinet 25 см — від $2124 до $3009 [price: UF xlsx Pricing A8, A222]
